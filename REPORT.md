# Отчёт о проделанной работе

Редизайн лендинга конференции «DevMeetup» (челлендж 2, `chellenge2.txt`).
Дата: 06.11.2026.

## Постановка задачи

Сохранить всю функциональность экрана, но:

- сделать обратный отсчёт главным акцентом первого экрана;
- оформить программу как временную шкалу или карточки вместо таблицы;
- показать билеты как карточки с ценой;
- вынести форму регистрации на видное место.

Источники: `chellenge2.txt` (задача), `REFERENCE.md` (желаемый результат), `START.md` (запуск).

## Что сделано

### Шаг 1. Разметка (`index.html`)

- Шапка: дата вынесена в плашку-кикер над заголовком, `#countdown` обёрнут в контейнер `#countdown-wrap`, добавлена кнопка-якорь «Зарегистрироваться» на `#register`.
- Программа: `<table id="programTable">` заменён на `<ol class="timeline">` — время слева, события карточками, спикер отдельной строкой.
- Билеты: `<ul>` заменён на `.ticket-grid` из трёх `<article class="ticket-card">` с ценой и составом; VIP выделен бейджем «Популярный».
- Регистрация: поля идут стопкой (убраны `<br><br>`), кнопка крупная.
- Добавлен `<meta name="viewport">` — иначе новая вёрстка на телефоне уедет.

### Шаг 2. Стили (`style.css`, переписан полностью)

- Тёмная тема: фон `#0b1120`, акцент `#fca311`, системный стек шрифтов (внешние не подключаются — страница открывается по `file://`).
- Отсчёт — крупный контейнер с рамкой и тенью, текст `clamp(20px, 4vw, 30px)`.
- Программа — таймлайн: вертикальная линия, точки, время табличными цифрами.
- Билеты — грид `repeat(auto-fit, minmax(200px, 1fr))`, карточки с ценой, VIP с рамкой и бейджем.
- Регистрация — блок с оранжевой рамкой и тенью, подсветка фокуса, крупная кнопка.
- Удалены мёртвые правила `#programTable` и `#tickets ul`.

### Шаг 3. Проверка

- **Узкий экран (375px)** — страница в iframe шириной 375px: горизонтального переполнения нет, внутренних скроллов нет.
- **Отсчёт** — тикает каждую секунду, `38 дн.` совпадает с `EVENT_DATE` = `2026-12-15T10:00:00`.
- **Форма** — пустая отправка блокируется (`valueMissing`), неверный email блокируется, валидная отправка даёт «Спасибо, … Билет «…» зарезервирован…» и сбрасывает поля.
- **Консоль** — ошибок нет.
- **Внешние ресурсы** — только `<link rel="stylesheet" href="style.css">`, ничего из сети.

## Ограничения, которые соблюдались

- `script.js` не изменялся — источник истины для отсчёта и отправки формы.
- Сохранены все ID, которые использует JS: `countdown`, `registerForm`, `regName`, `regEmail`, `regTicket`, `registerResult`.
- Сохранены `required`, `type="email"` и точные значения `select`: `Стандарт` / `VIP` / `Студенческий`.
- Никаких зависимостей, сборки и dev-сервера не добавлено.

### Конфликт референса и ограничения

`REFERENCE.md` просит «отдельные блоки дни/часы/минуты/секунды», но `script.js` пишет в `#countdown` одну строку через `textContent`. Разбить её на блоки без правки JS нельзя, поэтому акцент сделан стилями (крупный контейнер вокруг текста), а не новой разметкой.

## Замечания по инструментам проверки (не относятся к проекту)

- Браузерный инструмент не принимает `file://`, поэтому проверка велась через временный `python3 -m http.server` — в проект он не добавлен и остановлен после работы.
- Инструмент скриншота отставал на один кадр от DOM: после перезагрузки он снимал старое состояние (включая тестовые правки в DOM). Решено повторной съёмкой; на `file://` в обычном браузере этой задержки нет.

## Как увидеть результат

Открыть `index.html` двойным щелчком (или File → Open в браузере). Отсчёт должен тикать каждую секунду, а после заполнения формы и нажатия «Зарегистрироваться» — появляться сообщение с выбранным билетом.

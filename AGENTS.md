# AGENTS.md

Статический одностраничный лендинг конференции «DevMeetup». Нет сборки, сервера, пакетного менеджера, тестов и линтера: откройте `index.html` напрямую в браузере (File → Open). Команд запуска/проверки нет — проверка только вручную в браузере (тикающий отсчёт, сообщение формы после submit).

## Контекст задачи

- Это UI-редизайн, а не разработка функциональности. Источники задачи: `chellenge2.txt` (формулировка, имя файла с опечаткой), `REFERENCE.md` (желаемый результат), `START.md` (запуск).
- Править можно только `index.html` и `style.css`. `script.js` не трогать.
- Все тексты на русском — сохраняйте язык при любых правках.

## Критичные ограничения

- `script.js` — источник истины для поведения: отсчёт до `2026-12-15T10:00:00` и отправка формы. Он обращается к ID `countdown`, `registerForm`, `regName`, `regEmail`, `regTicket`, `registerResult` — эти ID нельзя удалять или переименовывать в `index.html`.
- ID секций (`hero`, `about`, `program`, `tickets`, `register`, `contacts`) и `programTable` используются только в `style.css` — их можно менять, но только синхронно в CSS.
- Форма: сохраните `required`, `type="email"` и точные `value` в `select` (`Стандарт`/`VIP`/`Студенческий`) — иначе перестанет работать обработчик и текст подтверждения.
- Конфликт референса и ограничения: `REFERENCE.md` просит «отдельные блоки дни/часы/минуты/секунды», но `script.js` пишет в `#countdown` одну строку через `textContent`. Разбить её на блоки без правки JS нельзя — выделяйте отсчёт стилями (крупный контейнер вокруг текста), не новой разметкой внутри.
- Никаких зависимостей, бандлеров и dev-сервера. Страница открывается по `file://`, поэтому внешние шрифты/иконки подключайте только осознанно: без сети они не загрузятся.
